# Repository workflow

Before changing this Git repository, read effective AGENTS.md files, fetch all remotes, and report path, current branch, upstream, worktree status and target. Work from the latest target on a clearly named feature branch; preserve dirty files and ask before destructive updates. Commit each verified increment atomically using repository history style, push to the configured upstream, and report ahead/behind, commits and checks before handoff. Never reset, stash, rebase, force-push or discard uncommitted work without approval.
